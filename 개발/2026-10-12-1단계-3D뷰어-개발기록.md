# 1단계 3D 뷰어 개발 기록

- 작성일: 2026-10-12
- 근거: `기획/2026-10-12-1단계-3D뷰어-기능정의서.md`, `디자이너/2026-10-12-1단계-3D뷰어-화면디자인.md`

## 만든 것
- `개발/viewer/index.html`: 브라우저에서 바로 여는 3D 뷰어 (three.js 0.160.0, CDN에서 불러옴)
- 모델 데이터는 `디자이너/3d-모델/model.js`를 그대로 읽는다. 데이터를 바꾸려면 디자이너 폴더에서 `python build_model.py`를 다시 실행한다.

## 여는 방법
- `개발/viewer/index.html`을 더블클릭 → 크롬/엣지에서 열림
- 인터넷 연결이 필요하다 (3D 라이브러리를 CDN에서 받음).
- 폴더 구조를 그대로 두어야 한다 (뷰어가 `../../디자이너/3d-모델/model.js`를 읽음).

## QA 후 고친 것
- 방 경계·문턱 자리에 바닥이 비어 흰 줄이 보이고 그 자리를 클릭해도 치수가 안 찍히던 문제 → 집 전체 바닥판 추가
- 치수 숫자가 방 이름표에 가려지던 문제 → 치수 라벨을 선 위로 띄움
- 평면도의 글자·화살표가 가는 벽 기둥으로 서던 문제 → 모델 생성 시 작은 검은 덩어리 제거 (벽 128 → 95개)

# 8단계 자동 저장 · 파일 내보내기·가져오기 개발 기록

- 작성일: 2026-10-14
- 근거: `PM/2026-10-14-8단계-자동저장-내보내기-기능정의서.md`, `디자이너/2026-10-14-8단계-자동저장-내보내기-화면디자인.md`
- 바꾼 파일: `개발/viewer/index.html`

## 구현
- **자동 저장:** `saveDraft()`가 `apt-autosave` 키에 `{ v, savedAt, combo, changed, state }`를 저장한다.
  - `renderComboNow()` 끝에서 부른다. 이 함수는 편집(markChanged), 조합·제안안 불러오기, 되돌리기 뒤에 항상 불리므로, 저장할 곳을 하나로 모을 수 있었다.
  - 처음 열 때는 `draftReady`가 켜지기 전까지 저장하지 않는다. 기본 상태가 저장된 작업을 덮어쓰지 않게 하기 위해서다.
- **이어서 열기:** 시작할 때 `restoreDraft()`가 저장된 상태를 `applyState`로 연다. `baseState`("가구 처음 자리로"가 돌아갈 자리)는 조합 이름으로 찾은 원래 상태(`comboBase`)로 다시 맞춘다.
  - 실패하면 기본 조합으로 연다(try/catch).
- **알림:** `showToast(text, actionLabel, action)`로 띄우고, 10초 뒤 저절로 닫는다.
- **내보내기:** `{ app: 'apt-3d-viewer', version: 1, exportedAt, title, combos, products, current }`를 Blob으로 만들어 `<a download>`로 내려받는다. file://에서도 된다.
- **가져오기:** 파일을 읽어 `importData`로 넘긴다.
  - 확인 창을 띄운 뒤 `remember()`로 되돌릴 수 있게 한다.
  - 조합은 이름 기준으로 합치고, 제품은 id 기준으로 고치거나 더한다.
  - 파일에 지금 화면 상태가 있으면 그 상태로 바꾼다.
- **버그 수정:** 상자(기타) 모양 제품에 `at`·`rot` 기본값을 넣었다. `stateFrom`은 `at`이 비어 있으면 집 가운데로 둔다.
- **QA용 공개:** `__viewer`에 `importData`, `currentCombo`, `changed`를 공개했다.

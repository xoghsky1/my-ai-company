# 4단계 제품 넣기 검수 리포트

- 작성일: 2026-10-13
- 기준: `PM/2026-10-13-4단계-제품넣기-기능정의서.md`
- 도구: `QA/검수도구/make-steps-제품넣기.py` → `steps-제품넣기.json` → `shoot.mjs`. 헤드리스 크롬에서 실제 뷰어를 열어 입력·클릭으로 확인했다.
- 콘솔 오류: 없음

## 결과
| 항목 | 확인 내용 | 결과 | 판정 |
|---|---|---|---|
| F1 입력 검사 | 이름 빈칸 / 크기 0 / `javascript:` 링크 | 각각 오류 문구, 제품 안 생김 | 통과 |
| F2 생성 | 소파 2200×950×800 넣기 | 화면 가운데 (4.61, 4.53)에 소파 모양으로 생기고 선택됨. 가구 탭 "내 제품"에도 나옴 | 통과 |
| F2 겹침 | 넣은 자리가 식탁과 겹침 | 빨간 표시 + "다른 가구와 겹침: 식탁" | 통과 |
| F3 견적 | 1,890,000 + 250,000 → 하나 빼기 | 2,140,000원(2개) → 1,890,000원(1개), 후보 전체 2,140,000원 유지 | 통과 |
| 되돌리기 | 빼기 Ctrl+Z → 넣기 Ctrl+Z → Ctrl+Y | 2개 → 1개(숨김) → 2개 | 통과 |
| F5 조합 | 저장 → B안 → 저장한 조합 불러오기 | 2,140,000원 → 0원 → 2,140,000원 | 통과 |
| F5 새로고침 | 새로고침 뒤 | 제품 2개 남음(기본 조합에서는 숨김), 조합 불러오면 다시 2개 | 통과 |
| F4 삭제 | 확인 후 삭제 | 목록·장면·저장소에서 빠지고 합계 250,000원 | 통과 |
| F6 정보 | 제품 클릭 | 가격·"상품 보기" 링크 표시, 이름의 `<b>`는 글자로 보임 | 통과 |
| 화면 | 제품 탭 전체 | 5개 탭이 한 줄에 들어가고 글자 잘림 없음 | 통과 |

## 수동 확인 필요

- 마우스로 직접 끌기는 기존 가구와 같은 코드라 따로 검사하지 않았다

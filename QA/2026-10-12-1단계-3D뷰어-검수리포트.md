# 1단계 3D 뷰어 검수 리포트

- 작성일: 2026-10-12
- 검수 기준: `기획/2026-10-12-1단계-3D뷰어-기능정의서.md`
- 방법: 헤드리스 크롬으로 뷰어를 실제로 열어 조작하고 화면을 찍어 확인 (`QA/검수도구/shoot.mjs`, 단계 파일 `steps-*.json`)
- 치수는 모두 평면도 기반 추정값이다. 실측 대조는 하지 않았다(실측 자료 없음).

## 기능 검수
| 항목 | 판정 | 근거 |
|---|---|---|
| F1 3D 집 표시 (벽·창·현관문·바닥·방 이름) | 통과 | 방 이름 12개 표시, 창 유리·창턱·현관문 자리 확인. 안방/아기방/옷방 이름 반영 |
| F2 회전·확대·이동, 시점 버튼 3개 | 통과 | 위에서/비스듬히/처음 위치로 전환 화면 확인. 벽 앞 약 1m까지 다가가 창틀이 깨지지 않음 확인 |
| F3 벽 높이 전환 (2.3m / 1.0m) | 통과 | 낮춘 벽에서 방 안이 보임 |
| F4 방 정보 | 통과 | 안방 클릭 → "약 2.9 × 2.5 m (추정)", 평면도 이름 침실1 표시. 빈 곳 클릭 시 선택 해제 |
| F5 두 점 거리 재기 | 통과 | 거실 가로 기대값 2.88m = 화면 2.88m. Esc로 첫 점 취소(1→0개), 지우기 후 0개 |
| F6 격자·방 이름 켜기/끄기 | 통과 | 끈 뒤 화면에서 사라짐 확인 |
| 화면 문구 '추정' 표시 | 통과 | 상단 배지, 방 정보에 (추정) |

1차 검수에서 실패한 2건(방 경계 바닥 빔, 치수 라벨 겹침)은 개발 수정 후 재검수에서 통과.

## 수동 확인 필요
- 실제 PC 브라우저에서 마우스로 직접 돌려 보는 손맛(회전 속도·확대 감도)은 팀장 확인 필요.
- 인터넷이 없는 환경에서는 열리지 않음 (CDN 사용).

## 개선 제안 (다음 단계 후보)
1. 방 사이 문 위에 벽(문틀 윗부분)이 없어 문 자리가 천장까지 뚫려 보임 → 문 위치를 데이터로 정리해 문틀·문짝 추가
2. "위에서 보기"가 원근 시점이라 벽 옆면이 비스듬히 보임 → 평면도처럼 보이는 정투영 시점 추가
3. 10cm 보조 격자가 바닥 위에 겹쳐 다소 복잡함 → 확대했을 때만 보이게
4. 방 크기는 외곽 상자 기준이라 ㄱ자 방(주방/식당 등)은 실제보다 크게 표기됨
5. 실측 자료가 생기면 치수 대조 검수 필요

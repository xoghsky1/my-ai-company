# 5단계 1인칭 걷기 시점 기능 정의서

- 작성일: 2026-10-13
- 팀장 요청: "1인칭 걷기 시점도 만들어 줄 수 있어?"
- 목적: 집 안을 사람 눈높이로 걸어 다니며, 가구를 놓았을 때의 통로·답답함·시야를 실제처럼 느껴 본다

## 1. 기능
| 번호 | 기능 | 완료 조건 |
|---|---|---|
| W1 | 걷기 시작·끝내기 | 보기 탭의 [걷기 시작]을 누르면 1인칭이 된다. 다시 누르거나 Esc를 누르면 끝나고, 시작 전 시점으로 돌아간다 |
| W2 | 시작 위치 | 보고 있던 화면 가운데가 집 안의 빈 바닥이면 거기서, 아니면 현관에서 거실 쪽을 보고 시작한다 |
| W3 | 움직이기 | W/A/S/D 또는 방향키로 앞·뒤·옆으로 걷는다(초속 1.4m). Shift를 누르면 2배로 걷는다. 마우스를 끌면 고개를 돌리고 위·아래를 본다 |
| W4 | 부딪힘 | 벽, 창, 현관문, 바닥에 놓인 가구는 통과하지 못하고 미끄러지듯 비켜 간다(몸 반지름 0.2m). 방문 자리와 안방–발코니 창(바닥까지 오는 창)은 지나갈 수 있다 |
| W5 | 눈높이 | 어른 1.6m / 아이 1.0m 중에서 고른다 |
| W6 | 지금 위치 | 화면 아래 안내 줄에 지금 있는 방 이름을 보여 준다 |
| W7 | 걷는 동안 | 벽은 전체 높이로 보이고, 시야각을 넓힌다(60°, 축척 보정 때 70°에서 낮춤). 가구 끌기와 치수 재기는 잠시 꺼진다. 클릭하면 가구·방 정보는 그대로 나온다 |

## 2. PM이 정한 기본값
- 방문은 열린 것으로 본다(문짝 모형이 없음).
- 휴대폰 터치 조작은 이번 범위에서 뺀다(뷰어는 PC 브라우저 기준).

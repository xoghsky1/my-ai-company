# 7단계 조명: 밤 모드와 기본 조명 vs 조명특화 비교 기능 정의서

- 작성일: 2026-10-13
- 팀장 결정: "밤 모드랑 기본 조명 vs 조명특화 옵션 비교로 가자"
- 목적: 분양 유상 옵션 **조명특화**를 신청할지 밤 화면으로 비교해 판단한다
- 근거 자료: 분양 안내 "조명특화 · 특화조명: 디밍/색온도 + 간접 엣지등(거실, 침실) + 스마트 스위치 고급형"

## 1. 기능
| 번호 | 기능 | 완료 조건 |
|---|---|---|
| L1 | 밤 모드 | 새 **조명** 탭의 [밤 모드] 또는 N 키로 켜고 끈다. 해·하늘빛이 꺼지고 배경이 어두워지며, 집 안 조명만으로 보인다 |
| L2 | 기본 조명 | 방마다 천장 가운데 LED 방등 1개. 주광색(5700K)·밝기 100% 고정, 켜기·끄기만 된다 |
| L3 | 조명특화 | 기본 방등에 **밝기(10~100%)**와 **색온도(2700~6500K)** 조절이 더해지고, 거실·침실(안방·아기방·옷방)에 **간접 엣지등**(천장 둘레 은은한 빛)이 생긴다 |
| L4 | 장면 | 조명특화에서 버튼 하나로: 일상(100%·4000K·간접등) / 휴식(50%·3000K·간접등) / 영화(방등 10%·간접등·2700K) / 밤 수유(아기방 간접등 15%·2700K, 복도 10%, 나머지 끔) |
| L5 | 나란히 비교 | [나란히 비교]를 켜면 화면을 반으로 나눠 왼쪽은 기본 조명, 오른쪽은 조명특화로 같은 시점을 동시에 보여 준다 |
| L6 | 방별 켜기 | 방마다 조명을 켜고 끄는 체크 목록 |
| L7 | 함께 쓰기 | 밤 모드에서도 1인칭 걷기·구역 편집·가구 편집이 된다. 걷는 동안에는 천장이 보이고, 간접등이 켜지면 천장 둘레가 밝아진다 |

## 2. PM이 정한 기본값 (팀장이 바꾸고 싶으면 알려 주세요)
- 기본 조명의 색은 일반적인 분양 기본 LED 방등에 맞춰 **주광색 5700K**로 잡았다.
- 조명 기구 위치는 실제 설계를 몰라 **각 방 가운데 천장**으로 추정했다. 간접 엣지등은 천장 둘레에서 0.25m 안쪽을 따라 둔다.
- 조명특화의 가격은 분양 안내에 없어 화면에는 "가격 확인 필요"로 둔다.
- 화면 밝기는 분위기 비교용이다. 실제 밝기(럭스)를 재는 기능이 아니다.
- 조명 설정은 조합 저장에 넣지 않는다(분양 옵션이라 집 전체에 하나).

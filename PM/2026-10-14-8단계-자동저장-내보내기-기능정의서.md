# 8단계 자동 저장 · 파일 내보내기·가져오기 기능 정의서

- 작성일: 2026-10-14
- 팀장 요청: "자동 저장이랑 파일 내보내기·가져오기 진행해줘"
- 목적: 새로고침해도 편집이 사라지지 않게 하고, 다른 PC·브라우저나 가족과 작업을 주고받는다

## 1. 기능
| 번호 | 기능 | 완료 조건 |
|---|---|---|
| S1 | 자동 저장 | 마감재·가구·조합 불러오기·되돌리기 등 화면 상태가 바뀔 때마다 브라우저에 바로 저장한다 |
| S2 | 이어서 열기 | 다시 열면 마지막 상태(조합 이름·"수정됨" 표시 포함)로 열고, 아래쪽에 "마지막 작업을 불러왔습니다 · [처음 상태로]" 알림을 10초 보여 준다. [처음 상태로]는 기본 조합으로 돌아가며 Ctrl+Z로 되돌릴 수 있다 |
| S3 | 처음 자리 | 이어서 연 뒤 "가구 처음 자리로"는 그 조합의 원래 자리(제안안·저장 조합·기본 조합)로 간다 |
| S4 | 파일로 내보내기 | 조합 탭 [파일로 내보내기]: 저장된 조합 전부 + 내 제품 목록 + 지금 화면 상태를 JSON 파일 하나로 내려받는다. 파일 이름 `우리집-인테리어-YYYYMMDD-HHMM.json` |
| S5 | 파일 가져오기 | [파일 가져오기]로 파일을 고르면 내용(조합 N개·제품 M개)을 확인 창으로 보여 주고, 확인하면 합친다: 같은 이름 조합·같은 제품은 파일 것으로 바꾸고, 없는 것은 더한다. 화면은 파일의 마지막 상태로 바뀌며 Ctrl+Z로 되돌릴 수 있다 |
| S6 | 잘못된 파일 | 이 뷰어 파일이 아니거나 내용이 깨졌으면 아무것도 바꾸지 않고 이유를 알려 준다 |

## 2. PM이 정한 기본값
- 조명 설정·카메라 시점·치수 재기 선은 저장하지 않는다(화면 보기 설정).
- 가져오기는 "덮어쓰기"가 아니라 "합치기"다. 이 브라우저에만 있던 조합·제품은 지우지 않는다.
- 파일에는 개인 정보가 없다(집 구조는 뷰어에 들어 있고, 파일에는 선택값만 있다).

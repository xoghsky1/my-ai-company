# 4단계 제품 넣기 기능 정의서

- 작성일: 2026-10-13
- 팀장 요청: "이름·크기·가격·링크 넣으면 뷰어에 가구로 생기고 견적 합산되게"
- 목적: 사려는 제품이 우리 집에 **들어가는지**와 **얼마인지**를 사기 전에 함께 확인한다

## 1. 기능
| 번호 | 기능 | 완료 조건 |
|---|---|---|
| F1 | 제품 입력 | 이름(필수), 크기 가로·깊이·높이 mm(필수, 10~5000), 모양(목록에서 선택), 가격(원, 비우면 0), 링크(선택, http/https만) |
| F2 | 뷰어에 가구로 생성 | "뷰어에 넣기"를 누르면 보고 있는 화면 가운데에 입력 크기로 생기고 선택된다. 다른 가구처럼 끌기·R 돌리기·겹침 경고·되돌리기가 된다 |
| F3 | 견적 합산 | 지금 조합에 놓인(보이는) 제품의 가격 합계와 개수를 보여 준다. 놓지 않은 후보까지 더한 전체 합계도 함께 보여 준다 |
| F4 | 내 제품 목록 | 제품마다 크기·가격·상품 링크, "이 조합에 놓기" 체크, 삭제(확인 창, 되돌릴 수 없음) |
| F5 | 저장 | 제품 목록은 이 PC 브라우저에 저장. 놓은 자리·보이기는 조합 저장에 함께 들어간다. 새로고침해도 목록이 남는다 |
| F6 | 선택 정보 | 제품을 클릭하면 정보 칸에 가격과 "상품 보기" 링크가 나온다 |

## 2. PM이 정한 기본값 (팀장이 바꾸고 싶으면 알려 주세요)
- **모양:** 실제 모양을 그리지 않고, 비슷한 기존 가구(소파·침대·수납장 등 15종)의 모양과 색을 빌린다. "상자(기타)"는 단순한 상자로 그린다.
- **견적 기준:** 큰 숫자는 *지금 보고 있는 조합에 놓인 제품만* 더한다. 조합을 바꿔 가며 안별 비용을 비교하는 용도다.
- **놓이는 자리:** 보고 있는 화면 가운데다. 겹치면 가까운 빈자리로 옮겨 놓는다(F7).
- **범위 밖:** 상품 링크에서 크기·가격을 자동으로 읽어 오기, 제품 사진 입히기, 수량, 배송비·시공비는 다음 단계로 미룬다.

## 3. 보완 (QA 개선 제안 1·2, 2026-10-13)
| 번호 | 기능 | 완료 조건 |
|---|---|---|
| F7 | 빈자리에 놓기 | 넣을 때 보던 자리가 벽·가구와 겹치면 가장 가까운 빈자리(5cm 간격, 방향 0°/90°)에 놓는다. 제품 전체가 한 방 안에 들어가야 하고, 욕실·실외기실·현관은 제외한다. 못 찾으면 보던 자리에 두고 알린다. 러그처럼 바닥에 까는 것은 옮기지 않는다 |
| F8 | 제품 수정 | 목록의 [수정]을 누르면 입력칸에 값이 채워지고 [수정 저장]·[취소]가 나온다. 놓인 자리는 그대로이고, 커져서 겹치면 알린다 |
| F9 | 되돌리기 | 제품 넣기·수정·삭제 모두 Ctrl+Z로 되돌린다 (삭제도 이제 되돌릴 수 있음) |

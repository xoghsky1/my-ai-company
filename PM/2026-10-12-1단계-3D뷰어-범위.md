# 1단계 3D 뷰어 범위 정리 (팀장 상의용)

- 작성일: 2026-10-12
- 명령: "1단계 시작" — 평면도로 치수를 추정해 브라우저에서 보는 3D 집을 만든다.

## 현재까지 준비된 것 (사실)
- 59㎡A 확장형 평면도 이미지 확보: `자료/59A_확장형_평면도.png`
- 디자이너가 평면도에서 3D 모델 데이터 추출: `디자이너/3d-모델/model.json`
  - 축척 1.82cm/px (전용면적 59.83㎡에 맞춘 추정), 벽 128개, 창·문 9개, 방 11개
- 방 용도 (팀장 지정): 침실1 = 안방, 침실2 = 아기방, 침실3 = 옷방
- 개발 에이전트 신설: `개발/`

## PM 제안 범위 (판단)
| 구분 | 1단계 포함 | 이후 단계 |
|---|---|---|
| 3D 집 | 벽·창·현관문, 방별 바닥 색 구분, 방 이름 표시 | 실측 치수로 보정 |
| 보기 | 회전·확대·이동, 위에서 보기 / 비스듬히 보기 전환 | 1인칭으로 걸어 다니기 |
| 치수 | 두 점을 찍어 거리 재기, 1m 격자 | 벽마다 치수선 자동 표시 |
| 인테리어 | 없음 (빈 집) | 바닥재·벽지·가구 조합 (2단계) |

## 리스크
- 치수가 모두 추정이라 실제와 수십 cm 차이 날 수 있음. 실측 자료가 들어오면 보정 필요.
- 천장 높이·창 높이는 평면도에 없어 일반적인 값으로 추정.

## 팀장 확인 사항
1. 위 1단계 범위로 진행해도 되는지
2. 천장 높이 2.3m 추정으로 진행해도 되는지
3. 보는 환경 (PC 브라우저만 / 휴대폰 포함)
4. 실측 치수 자료(모집공고, 카탈로그 등)가 있는지

## 팀장 결정 (2026-10-12)
1. 1단계 범위: PM 제안대로 진행 (빈 집 3D + 회전·확대 + 두 점 거리 재기, 인테리어는 2단계)
2. 천장 높이: 2.3m 추정, 화면에 추정 표시
3. 보는 환경: PC 브라우저
4. 실측 자료: 없음. 평면도 추정치로 진행

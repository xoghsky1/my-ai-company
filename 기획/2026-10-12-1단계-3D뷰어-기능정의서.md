# 1단계 3D 뷰어 기능 정의서

- 작성일: 2026-10-12
- 근거: `PM/2026-10-12-1단계-3D뷰어-범위.md` (팀장 결정 포함)
- 대상: 산성역 헤리스톤 59㎡A 확장형, 201동 1층
- 보는 환경: PC 브라우저 (크롬·엣지). 파일을 더블클릭하면 열린다.

## 1. 목표
빈 집을 3D로 띄워 구조와 크기를 눈으로 확인한다. 인테리어 조합(2단계)의 바탕이 된다.

## 2. 화면 구성
| 영역 | 내용 |
|---|---|
| 3D 화면 | 화면 전체. 집 모델이 가운데 놓인다. |
| 상단 바 | 단지·타입 이름, "치수는 평면도 기반 추정" 안내 |
| 도구 패널 | 시점 전환, 벽 높이 전환, 치수 재기, 표시 켜기/끄기 |
| 정보 영역 | 선택한 방 정보, 잰 거리 |

## 3. 기능

### F1. 3D 집 표시
- 벽, 창(유리), 현관문 자리, 방별 바닥을 표시한다.
- 벽 높이(천장고)는 2.3m 추정. 창은 바닥에서 창틀까지 높이(추정)를 반영한다.
- 천장은 표시하지 않는다(위에서 내려다볼 수 있게).
- 방 이름은 팀장 지정 용도로 표시한다: 침실1 → 안방, 침실2 → 아기방, 침실3 → 옷방. 나머지는 평면도 이름 그대로.

### F2. 시점 조작
- 마우스 왼쪽 드래그: 회전 / 휠: 확대·축소 / 오른쪽 드래그: 이동.
- 확대는 벽 표면 가까이(약 0.3m)까지, 축소는 집 전체가 작게 보일 때까지 가능하다.
- 버튼 3개: **위에서 보기**(평면도처럼), **비스듬히 보기**(기본), **처음 위치로**.

### F3. 벽 높이 전환
- **전체 높이**(2.3m)와 **낮춘 벽**(1.0m) 두 가지. 낮춘 벽에서는 방 안이 잘 보인다.

### F4. 방 정보
- 방 바닥을 클릭하면 그 방이 강조되고 이름, 대략 크기(가로×세로, 추정)가 정보 영역에 나온다.
- 빈 곳을 클릭하면 선택이 풀린다.

### F5. 두 점 거리 재기
- **치수 재기** 버튼을 켜면, 바닥이나 벽을 두 번 클릭해 두 점 사이 직선거리를 잰다.
- 두 점 사이에 선과 거리 표시(m, 소수 둘째 자리)가 3D 화면에 남는다. 여러 개 잴 수 있다.
- **지우기** 버튼으로 잰 선을 모두 지운다. 재기 모드에서 Esc를 누르면 진행 중인 첫 점이 취소된다.

### F6. 격자·표시
- 바닥 아래 1m 격자(10cm 보조선)를 켜고 끌 수 있다. 기본은 켬.
- 방 이름 표시를 켜고 끌 수 있다. 기본은 켬.

## 4. 범위 밖 (2단계 이후)
- 바닥재·벽지·가구 바꾸기, 유상 옵션 비교
- 1인칭 걷기, 휴대폰 터치 조작
- 실측 치수 보정, 문짝·창틀 상세 모양

## 5. 확인 필요
- 없음 (팀장 결정으로 모두 정리됨). 디자이너가 화면 배치·색을 정한다.

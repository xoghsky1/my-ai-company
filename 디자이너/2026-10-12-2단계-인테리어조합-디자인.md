## 1. 화이트 미니멀 방향
- 벽은 흰색 계열, 바닥은 밝은 우드 또는 흰 타일, 가구는 흰색·오트밀·연한 오크로 통일한다.
- 장식 요소는 줄이고, 바닥 판 무늬·타일 줄눈처럼 가까이 봐야 보이는 결로 질감을 낸다.

## 4. 화면
- 왼쪽 패널 위에 탭 4개: 보기 / 마감재 / 가구 / 조합. 활성 탭은 파란 밑줄.
- **마감재 탭:** 방 드롭다운 → 바닥재 견본 칩(색 사각형 + 이름) 목록 → 벽 색 칩 목록 → [전체 방에 적용] 버튼 → 유상 옵션 영역(아트월 스위치).
- **가구 탭:** 가구 목록(체크박스로 보이기) → 선택한 가구 이름·크기 → [90° 돌리기] [가구 처음 자리로]. 안내 문구 "가구를 끌어서 옮기고, R 키로 돌립니다."
- **조합 탭:** 이름 입력 + [저장] → 저장된 조합 목록(이름, [불러오기], [삭제]) → 안내 "이 PC의 브라우저에만 저장됩니다."
- 선택한 가구: 파란 외곽 상자. 벽과 겹치면 가구 전체가 붉은빛(#E5484D, 섞임 40%) + 정보 영역에 "벽과 겹침".

# 네이버 헬스케어 프로덕트 분석

> 작성일: 2026-10-02
> 조사 근거: 공개 자료(검색 요약) + **직접 사용 메모(본인)**
> 표기: ✅ 복수 출처 확인 / ⚠️ 단일 출처·요약만 확인 / 👤 직접 사용에서 얻은 관찰 / ❓ 확인 못 함

## 1. 서비스 개요
- 운영 주체: 네이버. 2026-10-01 헬스케어 전담 조직 신설 보도 ⚠️ (자세한 내용은 [도메인 개요](../00_도메인_개요.md))
- 한 줄 정의: 네이버 앱 안에서 증상체크·병원 예약·만보기·복약관리 등 건강 기능을 한곳에 모은 '헬스케어 홈' ✅
- 타깃 사용자: 일반 사용자(B2C). 가족 단위 사용은 아직 확인 못 함 ❓
- 수익 모델: 직접 과금 없음(트래픽·데이터 접점 목적으로 추정) ⚠️

## 2. 핵심 기능
| 기능 | 설명 | 확인 |
|---|---|---|
| 증상체크 | 증상·부위 입력 → 예상 병명과 가까운 병원 안내, 네이버 예약과 연동 | ✅ |
| 병원 예약 일정 | 네이버 예약 기반 일정 확인 | ✅ |
| 만보기 | 걸음 수 기록 | ✅ |
| 복약관리 | 날짜별 복약 내역과 증상 기록으로 복용 패턴 확인 | ✅ |
| 건강 지수·콘텐츠 | 자외선·대기·감기 지수, 건강 클립 콘텐츠 | ⚠️ |
| 실손보험금 신청 | 네이버페이 연동 | ⚠️ |
| 헬스 미션 | 앱에서 "커밍순" 안내를 확인. 상세 내용은 공개 자료에서 못 찾음 | 👤 / ❓ |

## 3. 직접 사용 메모 (2026-10-02)

> 본인이 쓴 메모를 정리한 것입니다. 해석이 틀렸으면 고쳐 주세요.

- 👤 **차별성이 약하다.** 쓰려고 보니 다른 앱에도 모두 있는 기능이라 *지금은 네이버를 쓸 이유가 아직 없다*고 느낌.
- 👤 **만보기:** 좋지만 기능이 많지 않아 보임. *(인바디 관련 언급이 만보기에 대한 것인지 인바디 연동에 대한 것인지 확인 필요)*
- 👤 **기기 연동:** 인바디뿐 아니라 **가정에서 이미 쓰는 체중계 앱의 데이터**도 연동되면 좋겠다고 생각함.
- 👤 **가족 관리 아이디어:** 가족의 건강 데이터와 **약 처방 내역**을 한곳에서 관리하면 좋겠다고 생각함.
- 👤 **예약 연계 아이디어:** 네이버 예약과 연동되는 구조를 활용해 건강 데이터와 병원 이용을 연결하면 좋겠다고 생각함.
- 👤 **헬스 미션(커밍순):** 사용자를 끌어올리기 위한 기능으로 보임. *확실한 보상도 중요하지만, **무엇을 내세울 기능인지**가 더 중요하다*고 판단.

## 4. 공개 자료로 확인한 관련 사실
- 네이버는 인바디 지분 8.5%(약 325억 원)를 인수하고, 체성분·생체 데이터와 네이버의 AI·클라우드를 결합한 맞춤형 건강관리를 준비한다고 밝힘 ✅
- 인바디는 약 1억 8천만 건의 체성분 데이터를 보유 ⚠️
- 비교 대상 — 삼성헬스: 걸음 수 대결(최대 10명), 가족·친구와 공유하는 '투게더', 뱃지 보상, 체중계 액세서리 연동 지원 ⚠️
- 비교 대상 — 골든케어: 가족 건강 기록 관리, 처방전·약봉투 촬영 기반 복약 알림, 병원 예약 ⚠️

## 5. 강점 / 약점 (잠정)
| 구분 | 내용 | 근거 |
|---|---|---|
| 강점 | 검색·예약·결제(네이버페이)가 이미 한 계정에 연결됨 | ✅ 공개 자료 |
| 강점 | 인바디 투자·세나클 인수로 기기·병원 데이터를 확보할 기반이 있음 | ✅ 공개 자료 |
| 약점 | 개별 기능이 기존 앱과 겹쳐 **쓸 이유가 약함** | 👤 |
| 약점 | 가족 단위 기능과 외부 기기(가정용 체중계 등) 연동이 확인되지 않음 | 👤 / ❓ |
| 약점 | 기록은 쌓이지만 이를 **행동(예약·복약 지속)으로 연결**하는 장치가 보이지 않음 | 👤 |
